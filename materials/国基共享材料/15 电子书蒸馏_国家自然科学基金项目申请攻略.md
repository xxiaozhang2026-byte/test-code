# 一、全书总蒸馏

## 1.1 一句话

一本**把"基金申请全流程"做成可计算、可自查、可解码的操作性攻略**：既讲"上会标准=综合评分+资助意见加权计算"（全书最独特的量化贡献），也讲"看函评意见的语言密码"（出现"但是""建议""值得商榷"即要警惕），并把立项依据的逻辑谬误、形式审查清单、计划任务书FAQ 全部表格化——**对评审机制的透明化程度，是已蒸馏诸书中最高的一本**。

## 1.2 全书逻辑链

```text
基金委现行规则（2024改革后：两类研究属性/限项/诚信）
        ↓
申请书各栏目写法（立项依据→参考文献→团队→可行性→题名摘要→代表作）
        ↓
形式审查自查（17项清单）──第一道程序性淘汰线
        ↓
通讯评审（3–5名小同行，综合评价A/B/C/D＋资助意见优先/可/不予）
        ↓
上会标准（综合评分＋资助意见分值加权，满分8分）──量化门槛
        ↓
会议评审（大同行，1.2–1.5倍送审、预投票、讨论低共识项）
        ↓
看评审意见解码 → 新一轮申报的方向调整（换个"口子"）
```

## 1.3 全书最重要的五个判断

1. **上会与资助是可以量化的**：综合评分=(4nA+3nB+2nC+1nD)/函评份数，资助意见分值=(4n_优先+2n_可资助)/函评份数，两者之和为"上会标准"，满分8分。这让申请人从"碰运气"转向"算得清自己差在哪一档"。`[作者经验/建议]`，非基金委公布的正式线。
2. **看函评意见要看"连接词密码"**：评语中出现"但是""但""建议""值得商榷""可能""其实""等"字眼，往往是"明褒实贬"的信号；真话藏在转折之后。
3. **立项依据有四大不成立逻辑**：①"未见报道由此推论要做"不成立；②"大家都在做因此我要做"不成立；③"机理/影响规律研究=科学问题"不成立；④"论文即研究基础"不成立——其中①正是书14失败标书"写'未见报道'却被本组文献打脸"的教训的规则化表述。
4. **科学问题从学科理论基础知识来，不从文献来**：文献带来的灵感大部分是"验证性跟风"；真正的问题应来自专业基础课/专业课知识体系中的未解之处。这与《凝练科学问题案例》"从真实需求出发"互补——一个是学科内部逻辑起点，一个是外部需求起点。
5. **"道"远大于"术"**：申请成败九成在选题创新（60%）＋研究基础代表作（20%）＋撰写逻辑规范性（10%），"技巧/情商"只占10%；青年道90术10、第一个面上道80术20。**写作技巧救不了选题硬伤**——此比例是序作者左根永的个人量化观点，非原书正文、非基金委规定。

## 第2章 一般性问题（学科代码/关键词/查重/同门）

### 本章核心

代码与关键词决定"谁来评你"，查重与同门规则决定"会不会被毙"。

### [原书核心观点]

## 第3章 立项依据（核心章）★

### 本章核心

立项依据怎么写：整体行文逻辑、四步撰写法、科学问题来源、创新三方式、四大不成立逻辑。

### [原书核心观点]

- **整体行文逻辑链**：立项依据 → 研究内容 → 科学问题 → 研究目标 → 试验方案 → 可行性 → 研究基础 → 特色创新，环环相扣（与《从技术问题到科学问题》"同一条科学主线"一致）。
- **一气呵成 vs 反复修改**：作者主张先一气呵成写出框架，再整体修改；反对逐句打磨导致逻辑碎片化。比喻："把初稿的猪改成大象"——烂初稿可以改好，但没有初稿就无法修改。
- **撰写四步**：①"颜值"（版面、图、可读性）②"不让人上当受骗"（逻辑严、无漏洞）③"舍我其谁"（凸显唯一性/必要性）④"精雕细琢"。
- **科学问题来源**：从学科理论基础知识（专业基础课/专业课）来，不是从文献来；文献灵感大部分是验证性跟风。
- **创新其实很简单**："两三句话说不清楚的肯定不是创新"——创新必须能一句话讲清。
- **创新三种方式**：对象创新 / 方法创新 / 应用创新；其中**应用创新=嫁接式，作者不建议**（把成熟方法搬去新对象，最难成科学创新）。

### [原书案例]（材料类，学逻辑不学词汇）

- **例3-1 去污粉**：从"怎样提高去污粉去污能力"这一技术问题，层层追问"污渍为什么难去→界面作用→表面活性剂结构→分子结构与界面性能的构效关系"，把工程问题转成科学问题。示范"技术问题→科学本质"的递进提问法。
- **例3-2 猫鼠基因编辑**：示范科学问题凝练的"目标—手段—机制"三层（目标是什么、用什么手段、背后机制是什么）。
- **例3-3 水冷壁裂纹**：指出申请人写"研究主要集中在……""鲜见报道"这类表述的问题——"研究集中在某处"不等于"我的切入有效"，"鲜见报道"若检索不严谨会被函评当场戳穿（与书14"2017年写'未见报道'被本组文献打脸"同一教训）。
- **卢柯院士系列**（孪晶铜/快速过热熔化从晶内/纳米铜超塑性/表面纳米化/素化材料）：反复用"从一个经典理论问题出发→找到反常现象→提出新机制"的凝练路径，示范"科学问题从基础理论来"。

### [作者方法论主张]

- **四大不成立逻辑**：①"未见报道由此推论要做"不成立；②"大家都在做因此我要做"不成立；③"机理/影响规律研究=科学问题"不成立（研究机理是任务，不是问题本身）；④"论文即研究基础"不成立（代表作≠研究基础，见第6章）。
- **三类谬误语录**（打磨申请书时删除）：空话（"具有重要意义"）、套话（"随着社会发展……"）、过度承诺（"彻底解决……"）。

### [对个人项目的转译]

- 立项依据破题应避免"皖江圩区传统村落防洪研究少见"式开场（逻辑①）——应以真实洪涝风险＋空间形态与防洪的科学关联性切入。
- 破题路径可双源：从学科理论来（聚落空间形态学/防灾工程学的未解点）+从真实需求来（圩区洪涝事实），对应本书"理论基础知识"与《凝练案例》"需求牵引"两条路线。
- 创新表述须能一句话讲清，且优先走"对象创新/方法创新"，避免"把既有韧性评价方法搬去皖江村落"这种应用/嫁接式。

### 边界

"20–30个参考文献""立项依据4–5页"等数字是作者经验，非硬规定。焊接/材料案例的技术内容不迁移。

## 第6章 可行性/研究基础/题名摘要

### 本章核心

可行性怎么写、研究基础是什么、题名与摘要的关系。

### [原书核心观点]

- **可行性=研究方案可行**：不是人脉广、设备多，而是"研究方案从理论、方法、数据、条件上都能落地"。
- **研究基础≠代表作**：研究基础是"问题前情铺垫"——围绕拟解决的科学问题，说明已认识什么、已掌握什么方法、已有什么前期证据；代表作是成果陈列。作者归纳三误解：把研究基础写成成果清单、写成团队介绍、写成设备清单。

### [原书案例]（例6-1~6-4 可行性"翻车"案例）

- 例6-1：夸大人脉（"与院士合作"但无实质分工）→ 评审质疑"为何由你主持"。
- 例6-2：写设备"随时可用"但属他人实验室 → 评审质疑可用性。
- 例6-3：双通讯/他引表述被评审质疑本人贡献。
- 例6-4：把非唯一通讯作者标成唯一 → 评审当场质疑，诚信受损。

### [作者经验/建议]

- 摘要=立项依据浓缩，题名=摘要浓缩；"摘要看前三句"——评审通常只细读前三句就形成第一印象。
- 题名一般不超过25字（作者引 GB/T 7713.1—2006 学位论文题名规则"一般不超过25字"，属写作规范非基金委硬性要求）。
- 摘要写作四要素：重要性/迫切性/必要性 + 科学问题 + 方法 + 预期认识。
- 表6-1 申请书撰写自查表（提交前逐项核对）。

### [对个人项目的转译]

- 可行性部分先回答"SWMM模型在皖江圩区村落的输入数据可得性、率定验证路径、多案例可比性"——这是评审最可能质疑的落点。
- 研究基础围绕"形态测度前期成果、已有淹没模拟/洪痕数据、韧性指标前期研究"铺陈，不写成论文清单。
- 题名控制在25字内、摘要前三句直击"洪涝风险—形态—韧性"主线。

## 第10章 函评与会评（核心章）★

### 本章核心

通讯评审与会议评审的量化机制、流程与看评语技巧。

### [原书核心观点]

- **上会标准计算**（作者口径，非基金委公布线）：
  - 综合评分=(4nA+3nB+2nC+1nD)/函评份数（A优/B良/C中/D差）；
  - 资助意见分值=(4n_优先+2n_可资助)/函评份数（优先资助/可资助/不予资助）；
  - **上会标准=综合评分+资助意见分值，满分8分**；书中附表10-1（5位函评）与表10-2（3位函评）的完整计算示例。
- **"5A被评下去"是谣言**：5A极少落选；常见误解是把"综合评价5A但资助意见未全优先"当作落选理由。
- **有C也能上会**：函评单子出现C不等于出局，取决于加权总分。
- **RCC评审机制**：申请人可评价函评意见的参考价值（4–1分：很有帮助/有帮助/帮助不大/没帮助，默认4分）——评审意见本身也进入质量反馈。
- **会评流程**：按上会标准的1.2–1.5倍送审（作者多处表述略有出入，见"内部不一致①"）→ 会评专家预投票 → 重点讨论"共识低"的项目（高分与低分之外的中段是讨论对象）。
- **会评必要性**：对比德国DFG、美国NSF、澳大利亚等国评审制度，论证会评对"函评分歧较大项目"的纠偏作用。

### [作者经验/建议]

- **看评语技巧**：凡出现"但是""但""建议""值得商榷""可能""其实""等"字眼要警惕——这些词往往预告评审的真正保留意见；"不同意资助但基础较好"类评语要读后半句。
- 会评专家构成：以学科大同行为主；项目须让"非最窄同行"也能看懂创新点与可行性。

### [对个人项目的转译]

- 立项依据与创新点必须让"大同行"（规划/建筑/灾害交叉背景）可读，不能只写给小同行（纯水文或纯建筑）看。
- 用户可自行估算"上会期望分"：假设5位函评的A/B/C分布与资助意见分布，测算加权分落在哪个档，据此倒推薄弱环节（如把创新性从B补到A）。
- 摘要"前三句"与"题名25字"直接决定大同行第一印象。

### 边界

上会标准计算公式、1.2–1.5倍送审比例、评审意见表结构均为本书作者口径/当年度版本，需以2027年实际文件核验。

## 第11章 为什么难

### 本章核心

基金难中的结构性原因。

### [原书核心观点]

- **非对称风险反馈**：写申请书的沉没成本高、反馈信息少、失败信息模糊——一次失败只能得到评语，得不到"差在哪里"的确定性解释。

### [对个人项目的转译]

若首报不中，不必否定整体方向，而是用评语定位"口子"是否需要调整（对象/尺度/方法切入），并系统补前期数据与实证。

## 案例卡一：例3-1 去污粉（立项依据层层递进法）

- **出处**：第3章立项依据，例3-1；主版第3章。
- **案例要义**：从技术问题"怎样提高去污粉去污能力"出发，不直接答配方，而是逐层追问：污渍为什么难去→污渍-界面作用→表面活性剂分子结构→分子结构与界面性能的构效关系。
- **写作/论证逻辑链**：技术问题（怎么做）→ 机理问题（为什么）→ 结构问题（什么在决定）→ 科学问题（构效关系），每一层比上一层更接近"可研究的科学本质"。
- **可迁移的逻辑**：立项依据破题段的"层层递进提问法"——技术表象→现象机理→关键结构→科学问题，四步结构可直接套用。
- **不可迁移**：去污粉/表面活性剂的技术内容与构效关系语言。
- **对本项目的转译**：破题链路可写成"皖江圩区村落防洪能力不足（技术问题）→ 洪涝淹没过程如何被聚落形态改变（机理问题）→ 哪些空间形态结构在决定洪水传播/滞蓄（结构问题）→ 空间形态—洪水响应—防洪韧性的耦合机制（科学问题）"。此链路为工作假说，需G1（尺度）G2（中介）G3（阈值）验证。

## 案例卡二：例3-3 水冷壁裂纹（"鲜见报道"表述雷区）

- **出处**：第3章立项依据，例3-3；主版第3章。

- **写作/论证逻辑链**：否定式破题（"没人做"）→ 必须有可核查的检索/查新支撑；肯定式破题（"问题真实且关键"）→ 不依赖"没人做"。

# 三、原书方法转译到个人项目

## 3.1 当前工作模型

### [项目映射/工作假说]

```text
皖江圩区传统村落空间形态结构
        ↓
洪水淹没/传播/滞蓄/排散过程（SWMM情景模拟＋形态转译）
        ↓
村落功能维持、恢复与适应能力
        ↓
防洪韧性（状态向量/阈值/标度规律）
```

该模型只能作为工作假说，不能表述为已证实规律。G1（尺度缺位）G2（中介缺环）G3（阈值缺测）是用户方案框架，非本书观点。

## 3.2 候选关键科学问题

- **候选一（G1尺度）**：不同空间尺度（街巷—组团—村落—圩区）下，哪些形态关键结构主导洪水响应？
- **候选二（G2中介）**：洪水响应过程在空间形态结构与防洪韧性之间是否起中介作用、路径如何？
- **候选三（G3阈值）**：形态—韧性关系是否存在阈值/标度规律，临界条件是什么？

按本书第3章"科学问题从理论基础知识来"：以上问题的学科理论根可落在聚落空间形态学、过程-响应关系与非线性系统理论，而不只是文献缺口。

## 3.3 变量体系

| 层级 | 可能变量 | 当前状态 |
|---|---|---|
| 空间形态 | 街巷连通性/空间句法指标、建筑密度、滨水界面、圩堤-聚落关系、组团结构 | 需定义与筛选 |
| 洪水响应 | 水深、流速、淹没范围、汇流/滞蓄/排散时间、可达性变化 | 需SWMM情景模拟验证 |
| 防洪韧性 | 功能维持、恢复时间、避险可达性、蓄滞能力、适应能力 | 需操作化定义 |
| 条件变量 | 洪水重现期、圩堤状态、排水设施、地形、人口管理 | 需控制或分层 |

## 3.4 方法与证据

- 空间句法＋多尺度形态测度：表征空间结构；
- SWMM：情景化洪水模拟（输入数据可得性、率定验证为可行性关键）；
- 洪痕、遥感、实地调查：模型校准；
- GRA/SPC：仅在明确变量关系与数据质量后使用，不自动称创新；
- 中介效应检验/结构方程：检验"形态—洪水响应—韧性"路径，须与过程证据互补。

按本书第10章"上会标准"思想：为每个科学问题预先设定"可证伪的判定证据"，如"若某形态变量在水力模拟中无显著效应则拒斥对应假说"。

## 3.5 必须保留的替代模型

1. 空间形态直接影响韧性，不经洪水响应中介；
2. 洪水响应主要由地形与圩堤工程决定，形态作用弱；
3. 形态与响应仅相关、非因果；
4. 不同尺度主导变量不同，无单一指标可解释；
5. 村落类型/洪水情景改变形态作用方向。

本书"四大不成立逻辑"警示：任何替代模型被排除，都要有证据（模拟对比/统计检验），不能靠"未见报道"排除。

## 5.2 创新"一句话"模板

## 5.3 上会标准自查表（改写自第10章公式）

- 假设5位函评，预估综合评价分布（A/B/C/D）与资助意见分布（优先/可/不予）；
- 计算综合评分=(4nA+3nB+2nC+1nD)/5；
- 计算资助意见分值=(4n_优先+2n_可资助)/5；
- 两者之和对照8分满分定位缺口档位；倒推"把哪些栏目从B补到A"。

## 5.4 看评语解码清单（改写自第10章）

- 出现"但是/但/建议/值得商榷/可能/其实/等"→ 重点读该句后半；
- "基础较好但创新性一般"→ 创新性是短板；
- "创新性较好但可行性存疑"→ 方案/数据/条件需补强；
- "研究集中在…鲜见报道"评语复述≠认可 → 检查自己破题是否有可核验依据。

# 七、一页纸总蒸馏

本书对皖江圩区传统村落防洪韧性面上项目（E0802）最有价值的不是写作技巧，而是**两把"透明化"工具＋一组红线意识**：

**① 上会标准的量化自查（第10章）**——把"基金申请是玄学"拆解为可计算的三档：综合评分＋资助意见分值→加权总分。用户可在定稿前估算自己的函评分布，定位短板（创新性？可行性？基础？），并把每个科学问题配好"可证伪判定证据"。

**② 看评语的语言密码（第10章）**——"但是/建议/值得商榷"之后的半句才是评审真意。这决定二报时改什么、怎么改，与书14"换切入点"策略和本书第11章"换个口子就能中"互相印证。

**③ 红线意识（第1/2/3/6/8章＋附录F）**——挂名、查重、形式审查、"鲜见报道"式破题、可行性夸大、双通讯、预期成果含糊，都是可一票否决或折损分值的雷区。对首次面上申报，**可行性（SWMM在圩区村落的数据可得性与率定）与破题方式（避免否定式开场）**是本书给出的两个最具体的落点。

## 原书定位

一本以材料学科作者视角写就的**基金申请规则与评审机制透明化攻略**，2025年第2版已反映2024年改革。政策数字、上会计算公式、道术比例均须区分"作者口径/序作者观点/基金委规定"三档，以当年度指南为最终准绳。技术内容（焊接/金属）仅作参照系。
