## 一、总评

单案例方法示范型论文，真实贡献四条（均站得住）：

1. 带建筑学语义的"形态—模型"转译（院落/街巷断面/滨河界面/街巷—建筑分隔四类函数）；
2. 同一形态在边界切换下的"运行状态反转"（R0–W2 无雨也淹、W0≈W1、倒流支路先于雨峰激活）；
3. 形态作用是"再分配"而非"总体削减"（C0 几乎不动、P0 局部集中、U1 减倒灌却增内循环）；
4. "材料连续 ≠ 功能连续"的遗产保护重述。

核心风险：标题承诺"韧性"，正文只测了"响应/暴露"；几个关键结果（100% vs 1%、转制区间精度、P0/C0 的解释强度）存在会被审稿人抓住的实质问题。

## 三、必须处理（决定能否送审，A–F）

- [ ] **A 标题"韧性"错位**：标题/摘要写 "Flood Resilience"，但全文只测响应/严重度指标（深度、严重节点数、满流段、溢流通量、外部入流），无恢复维度、无 Res=1−Sev、无阈值型韧性量化。**建议改题为 "flood response / hydraulic vulnerability / compound-flood mechanisms"**，把"韧性"从因果主张降为 Discussion 前景；§2.1.2 的诚实声明已到位，但标题没收回来。
- [ ] **B 方差分解近同义反复**："边界解释 87.9–100%、形态主效应 0–1.06%"是实验设计必然产出（W2 是 on/off 开关 + 只有 C0/P0 两个联合扰动 + 聚合指标取全村尺度）。**不等于形态不重要，只说明被测扰动不移动聚合总量**。改三处：①明确标注"该扰动集内的描述性分解"；②摘要/结论各加一句"聚合指标对受测扰动不敏感=局部再分配而非形态影响缺位"；③把"形态在局部起作用"提到与"河流水位主导"并列。
- [ ] **C P0 联合扰动无法归因**：P0 同时改输送/蓄水/垂向分隔三件事，§4.2 仍在过度解读。**要么拆成三个子扰动，要么明确把 P0 降级为"断面关系整体探索性压力测试"**，局限列一条、软化 §4.2 因果措辞。
- [ ] **D C0 零结果可能是真空检验**：需补直查——报告 M0 基准下院落相关连接段**流量占比**。若本就近干，则 C0 对"院落作用"什么也没证明，摘要"courtyard drainage changes the point..."的机制主张悬空。
- [ ] **E 转制区间 114.85–114.95 m 精度虚假**：0.10 m 区间落在 2.0–2.5 m 基准校正的 0.5 m 不确定之内；Γ 仅 4 水位点（3 区间）且内部 min–max 归一化循环。**明确写：绝对量不可外推，稳健的是相对位置 + S−→S+ 状态变化**；理想做法加基准敏感性（2.0/2.25/2.5）或补 1–2 个水位点。
- [ ] **F 状态向量 S=[F,C,E] 术语问题**：F/C/E 全是输出/响应指标，S 是"运行状态"描述量，**非韧性状态**。标注 "operating-state descriptor，非 resilience state"，避免与项目 S={d,t} 口径打架；Ψ=√[(F²+C²+E²)/3] 等权 RMS + F 内部双重聚合、权重未交代，补权重敏感性或简化为分列 F/C/E。

## 四、建议加强（提高说服力，G–J）

- [ ] **G 提升 H14/J1 残差为中心性不确定性**：0.71 m 与 W0→W2 深度变化、P0 效应同数量级。专设一段不确定性讨论，明确"仅支持相对/方向性比较"，2D 地表耦合列为最可能解决路径（接项目 1D–2D 计划）。
- [ ] **H 负荷率—水深正相关的同义反复风险**：1D 网络"相邻段满流"与"下游节点积水"机制耦合，ρ=0.58 部分由构造产生。补一句承认近循环性，强调真正有价值的是调整后仍存活的静态变量。
- [ ] **I 流速/d·v 缺位明说**：严重度只用深度单判据（>0.15 m/30 min），未纳入 d·v 涉水安全包络。加局限一句"深度单判据为保守简化"（支撑而非抢先项目 d·v 工作）。
