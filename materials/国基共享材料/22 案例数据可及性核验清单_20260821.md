# 22 案例数据可及性核验清单

> 用途：按 `01 选题与科学问题_补充建议_20260817` §六/§七 的准入标准（A/B/C 类）与 SWMM 适用性预实验要求，对皖江三梯度候选案例做**数据可及性逐项核验**。**选题冻结前提：至少两个 A 类核心案例通过准入**（§十一）。
> 使用：实地调研 / 联系相关部门时逐项打勾；每项标注【已得】【可获取】【缺失】并记来源。数据不足的案例允许降级为 B/C 类，不为维持样本数制造伪精确阈值（§七）。

## 一、通用数据核验项（每村必核）

> 标注用途：**①**SWMM 建模 / **②**形态量化（空间句法/指标）/ **③**阈值识别（状态向量 S={淹没深度, 淹没历时}）/ **④**模型校准验证。

| # | 数据项 | 用途 | 建议获取渠道 | 状态 |
|---|---|---|---|---|
| A1 | DEM 数字高程模型（分辨率 ≥12.5m 为底线；圩区建议 ≤5m 或局部 1m） | ①②④ | 地理空间数据云（SRTM/ASTER/ALOS 12.5m）；自然资源部门"国土空间一张图"；无人机航测（自采） | ☐ |
| A2 | 村落及汇水区范围界线（汇水面积） | ① | 地形分水岭推演 + 现状调研核实 | ☐ |

## 一·附 线上预查结论（2026-08-21）

> 用途：把 §一 通用项中**可线上自助获取**的先查证，锁定首轮行动，把需部门/实地的留给实地。判定标注【线上可自助】/【需部门】/【需实地】。

| # | 数据项 | 线上预查判定 | 具体动作（首轮） |
|---|---|---|---|
| A1 | DEM | **【线上可自助】** 地理空间数据云（gscloud.cn，注册后免费下 SRTM 90m / ASTER GDEM 30m / ALOS 12.5m）；ALOS 12.5m 亦可从 ASF（EarthData）下 | 首轮下载 **ALOS 12.5m** 覆盖五村（查济/西河/孔城/大通/东流），验证是否能分辨街巷与圩堤走向；圩区局部 ≤5m/1m 仍须国土一张图或无人机（**12.5m 对圩区平坦地形可能不足，据此定 DEM 是否合格**） |
| C1 | 气象 | **【线上可自助】** 中国气象数据网（data.cma.cn）注册后申请**逐小时降水**，科研用途需填单位信息 | 邻近站：泾县、芜湖、桐城（安庆域）、铜陵、东至；一次性申请五站多年逐时序列；注意审批周期（提前 2-4 周） |
| C2 | 暴雨强度公式 | **【线上可查证】** 省住建厅/各市住建局已公布（芜湖 2023 新版公式已确认存在） | 泾县用宣城公式、西河用芜湖公式、孔城用安庆公式、大通用铜陵公式、东流用池州公式——逐个核对各市**最新版本与适用边界** |
| B5 | 长江干流水位 | **【部分线上】** 长江水文网实时水情可查大通站水位（大通站即铜陵，印证 §2.3 "水位资料预期较全"）；历史整编序列需长江委/水文局 | 先记录大通站近年**汛期最高水位序列**（线上可得），作外洪边界量级参考；完整整编走部门 |
| D4 | 历史影像 | **【部分线上】** 天地图历史影像可作定性对照 | 村落级分辨率通常不足，仅作形态演变定性参考，精细图档仍需住建/文物部门或无人机 |
| B1/B2/B3 | 水系矢量/圩堤高程/闸站调度 | **【需部门】** 水利局河湖划界成果、圩区工程档案 | **圩区案例（西河/孔城/大通）卡点在此**：线上解决不了 B2 圩堤矢量与堤顶高程，必须列为首批部门接洽项 |
| F1/F2/G1 | 实测淹没/灾情记录 | **【需部门/需实地】** 水利局、村委会、县志 | 2020.7 皖南洪水场次记录优先访谈 |

**首轮行动排序建议**（可并行）：
1. 我侧：ALOS 12.5m DEM 下载与五村范围裁切（确认可下后即执行）
2. 我侧：中国气象数据网账号注册 + 五站逐时降水申请（需你提供单位信息）
3. 你侧（放榜后）：水利局接洽圩区 B2/B5（圩堤高程、内外水位差）
4. 线上查证：五市暴雨强度公式最新版 + 大通站水位序列

## 二、三梯度候选案例逐村核验

> 初始准入**建议**（推测，以核验结果为准）：查济＝A 类候选；西河＝A 类候选；孔城＝A/B 待核；大通＝A/B 待核（江心洲圩堤是难点）；东流＝B 类候选。渔梁村＝**方法先导**（钱塘江水系，不作皖江主体案例，§六）。每村至少达到"A1+B1+C1+D1+D4+F1"齐备才可判 A 类。

### 2.1 山区支流梯度——查济村（泾县）

| 核验点 | 关注 | 状态 |
|---|---|---|
| 汇水区界定与山洪河道 | 查济河+周边山体汇流；山区短历时强降雨 | ☐ |
| 村庄空间图档 | 世界写生基地、文献/测绘相对丰富，D1/D2 预期可得 | ☐ |
| 历史洪水记录 | 山洪场次（2020.7 皖南暴雨） | ☐ |
| 村落内部水系 | 查济河穿村，桥涵/水口现状 | ☐ |

### 2.2 沿江圩区梯度——西河古镇 / 孔城古镇

| 核验点 | 关注 | 状态 |
|---|---|---|
| **圩堤高程与堤防档案（B2）** | **圩区最脆弱项；须确认圩堤矢量与堤顶高程可获取** | ☐ |
| 圩口闸站调度（B3） | 外洪顶托与内排的关系 | ☐ |
| DEM 精度（A1） | 圩区地形平坦，12.5m 可能不足，需确认 ≤5m 或局部 1m 来源 | ☐ |
| 内外水位差资料（B5） | 长江/青弋江水位与圩内水位 | ☐ |
| 古镇空间图档 | 西河为传统水运古镇，历史测绘/图档相对多 | ☐ |

### 2.3 干流口岸 / 江心洲梯度——大通古镇 / 东流古镇

| 核验点 | 关注 | 状态 |
|---|---|---|
| **江心洲圩堤（和悦洲）** | 洲圩堤防与岸线冲淤；**与江堤不同体系，须单独核验** | ☐ |
| 长江干流水位（B5） | 干流水文站（大通站即位于此——水位资料预期较全） | ☐ |
| 口岸/洲头形态 | 码头、老街、洲体形态的历史演变 | ☐ |
| DEM 精度（A1） | 洲滩微地形 | ☐ |

## 三、SWMM 适用性预实验核验（2026-10-16 前，§七）

> 预实验目的不是出阈值，而是判断**哪些案例适合 SWMM 核心模拟、是否需要 HEC-RAS/二维模型补充、圩堤河道边界如何表达、校准数据从哪来**。

- [ ] 至少选取 **1 个圩区案例 + 1 个山区案例** 试建 SWMM（用现有 DEM/降雨）
- [ ] 圩区案例试算外洪边界：SWMM 能否表达圩堤漫溢与河道回水？若不能 → 记录需补 HEC-RAS 或二维模型
- [ ] 校准数据盘点：F1/F2 是否足够支撑验证（哪怕历史单场次）
- [ ] 产出：每案例「适合 SWMM 核心模拟 / 需补充模型 / 降级」三选一结论

## 四、阈值冻结相关数据（S={淹没深度, 淹没历时} 观测来源）

> 按 `01 补充建议` §五，S 语义已按 Su 2024 摘要级核验修订（见冻结版阻塞依赖#1）：S={淹没深度, 淹没历时} 为响应产物；C（形态结构·自变量）、E（环境情景·控制变量）不入 S。冻结前须明确各维度的观测/计算指标与时间序列。以下为数据侧需同时盘点的项：

- [ ] 淹没深度观测来源（F1 实测 / SWMM 模拟输出 / 历史标记水位）
- [ ] 恢复能力判据数据（灾后功能恢复时间：访谈/报道）
- [ ] 灾前-灾中-灾后时间序列是否有任何实测段（多数村落无——须明确模拟为主、实测校准）
- [ ] 主阈值类型定稿：以 {淹没深度, 淹没历时} 为载体的**双阈值**（深度耐受阈值＋历时耐受阈值，Su 2024 摘要级已核；统计断点为识别手段），叠加"洪水响应导致关键功能状态转折"（机理约束·鱼梁村法）

## 四·附 共线性条件标准（2026-08-23 省基讨论收敛回写）

> 形态—梯度共线性对案例设计的约束（精确版）：
> - **国基 G2 中介＝模型化中介**（单村模型内加/去响应通道的反事实对照）——单村内完成，**不受梯度内形态变异约束**，不要求每梯度多村；
> - **"每梯度≥2–3 村"仅在国基从属问题一升级为梯度间统计比较假设时**才需要（当前定位＝G1 尺度下沉的环境多样性验证，非统计比较）；
> - 若将来升级，本项转硬标准；当前为**条件句**，不作案例准入硬门槛。
