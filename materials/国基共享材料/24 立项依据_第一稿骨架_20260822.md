## 一、研究意义（灵魂五问·第 1 问前半）

### 1.1 国家需求与政策窗口

- **长江国家文化公园**（官方全称，不写"长江文化公园"）提出到 2027 年初步形成保护传承协调推进格局；本项目申报年（2027）与第一阶段目标收官重合。`【待核】具体政策表述以当年规划/文件为准，来源见 18 文献前沿检索`
- 传统村落保护与乡村振兴持续推进，遗产"活态保护"要求从"保存可见形态"走向"维持发挥功能的空间关系"。
- **政策名与科学问题的分工**（07 决策已定）：政策名进立项背景，不进题目。

### 1.2 现实问题（真实问题，非技术任务包装）

- 沿江传统村落长期面临"**形态保存**"与"**防洪安全**"的现实矛盾：历史营建智慧（避水—导水—蓄水）多为定性归纳，**缺乏现代重现期情景下的量化检验**。
- 2020 年安徽歙县"7·7"暴雨洪水等事件佐证沿江村落防洪脆弱（[[shexian-20200707]] 在库）。`【待补】沿江/圩区具体灾情数据`

### 1.3 学科意义（三缺口一句话预告）

现有"形态—洪水量化"在城市/街区尺度已成熟，但**尚未下沉到传统村落尺度**；"形态→洪水"已有物理模型，却**未延伸至"洪水→韧性"、未基于真实村落形态**；村落尺度**以水力状态量定义系统韧性/失效阈值**仍是空白。详见 §2.5。

## 二、国内外研究现状及分析（灵魂五问·第 2 问）

> 每小节 = 已有研究贡献 → 不足 → 引出缺口。论证句尽量直接取自 09 综述 + 21 选题论证。

### 2.1 韧性理论的源流与多维度演进

- Holling（1973）区分工程韧性（恢复速率）与生态韧性（多稳态与阈值）[[holling1973]]；
- Cutter 等（2003）SoVI 将脆弱性量化为多维空间分布[[cutter2003]]；Cutter 等（2008）DROP 模型将韧性嵌入"抗扰—吸收—恢复—适应"多阶段过程[[cutter2008]]。
- **不足**：韧性测度共识（过程性 + 多维性 + 空间性）已建立，但"空间形态"作为显性介质的**定量承载**尚未在村落尺度落实。

### 2.2 传统村落防洪营建智慧（选址—形态—理水）

- 选址智慧：徽州[[wangyihui2025]]、秦巴山区[[qinba2025]]（q 值待核拆分）、秦岭北麓峪口[[ouya2024lingyukou]]；
- 形态响应：沁河凸/凹岸"方格—自由"分异[[qinhe2025]]、东莞梳状格局 + 水塘调蓄[[jiangbian2025]]、粤西三类型[[yuexishui2025]]、空间句法证实水要素反作用于街巷构形[[meihua2024]]；
- 理水工程：于家古村[[yujia2025]]、本寨村[[benzhai2026]] SWMM 量化巷道排水—池塘调蓄径流削减。
- **不足**：以"案例描述 + 定性归纳"为主，**形态特征与水文响应之间的量化因果链尚不完整**——这正是本研究的切入点。

### 2.3 空间形态测度与洪水模拟方法

- 形态测度：空间句法[[meihua2024]][[copenhagen2026]]、城市形态作非结构防洪工具[[safizadeh2022]]；
- 淹没模拟：SWMM / HEC-RAS / MIKE-21；SWMM 已用于乡村降雨—径流概化[[huangtu2025]]；`【待核】郑州/深圳/遥感制图等仅作情景背景，见 §五 B 类`
- 驱动分析：Geodetector、随机森林等[[qinba2025]][[fdurf2025]]。
- **不足**：工具链齐全，但**未对接为统一的"形态—响应—韧性"分析流程**。

### 2.4 韧性评估与规划响应

- AHP+GIS 三维韧性指数（宝堰[[baoyan2025]]）、分级防控（门头沟[[mentougou2025]]、京西[[jingxi2025]]）、CAS 六维测度[[caslishi2025]]。
- **不足（方法红线）**：多为**静态指标 + 专家权重 + 分级**，指标为拓扑/几何量，**无水力过程**；"分级 ≠ 系统转制阈值"。

### 2.5 研究缺口汇总（核心段，可直接入正文）

> 以下三段来自 21 选题论证 §二"加固后表述"，均已过反例击穿，可送审。

1. **G1 尺度缺位**：村落尺度 SWMM 止于单村性能评估（于家/本寨/石垭子），未见跨案例系统比较，亦未见将村落形态系统（院落—巷弄—塘池）转译为水力系统并检验其洪水响应的研究。
2. **G2 中介缺环（核心创新）**：城市街区尺度已建立"形态→洪水"物理模型（Balaian et al., 2024, *Nat. Commun.*，深度 ∝(1−φ)(1+bχ)/√α），但未延伸至"洪水→韧性"阈值/转制环节、未下沉传统村落尺度、且基于合成方形形态而非真实村落形态转译；国内街区形态韧性量化（luoyang→taiyuanjie→doumen）均为静态指标 + 专家权重 + 分级、无水力过程——**"村落形态→水力系统转译→洪水响应→韧性"的完整中介路径仍未检验**。
3. **G3 阈值缺测**：系统级韧性阈值识别停留在城市排水系统（Mugume）与城市扩张形态（Zhu）尺度；村落尺度仅有"建设强度—效益"设计优化区间（lianghuaqiu，7%~9%，判据为专家评分非水力状态量）——**以水力状态量定义村落形态系统的韧性/失效阈值仍为空白**。

## 三、科学问题与研究假设（灵魂五问·第 3 问）

> 采用 2026-08-22 逐条校准后的版本（机制为中心、梯度为设计、阈值为结果）。`【待冻结】9 月上旬与题目方案一并定稿`

### 3.1 关键科学问题

- **主问题**：皖江传统村落空间形态结构，**是否以及通过哪些**洪水响应过程（承接、汇流、滞蓄、排散等）影响防洪韧性？其**作用方向、中介路径与尺度边界**如何？
- **从属问题一（梯度 = 设计）**：在控制地形、水文情景与聚落类型后，山区支流—沿江圩区—干流口岸村落之间，上述关系是否表现稳定的梯度异质性？
- **从属问题二（阈值 = 结果）**：空间形态与洪水响应之间是否存在导致功能状态转折或系统失效的关键条件，该阈值如何以水力状态量界定与识别？

### 3.2 研究假设（可证伪，各配一条证伪判据）

- **H1**：村落形态的**系统组织**（街巷连通与冗余、圩堤连续性、水口开闭关系等）比单一形态指标更能解释洪水响应差异——**若系统组织指标在控制地形与排水条件后不再增加解释力，则 H1 被推翻**。
- **H2**：形态对韧性的作用**主要经由洪水响应过程**（中介）实现——**若直接效应在跨案例中稳定强于中介效应，则 H2 被推翻**。
- **H3**：梯度异质性源于水文—地形梯度本身——**若梯度差异来自案例类型或数据差异而非水文梯度，则 H3 被推翻**。

### 3.3 差异化定位（对照最接近研究）

| 对照方 | 他们在哪 | 本项目多做什么 |
|---|---|---|
| 王益团队（徽州防洪选址智慧） | 定性归纳 | 皖江，形态—响应—韧性定量链 + 中介检验 |
| 国际城市尺度（Balaian/Zhu/Liang） | 城市单尺度 | 传统聚落尺度 + 跨案例 + 阈值 + 真实形态转译 |
| 国内街区形态韧性（luoyang 族） | 静态指标 + 分级 | 水力过程 + 状态向量阈值 |
| 村落 SWMM 先例（于家/本寨/石垭子） | 单村性能评估 | 流域梯度多案例系统比较 |

## 四、研究难点与应对（灵魂五问·第 4、5 问）

### 4.1 难点（3 个，均已在 21/22 标记）

1. **圩区案例数据可及性**：B2 圩堤矢量需部门数据（高）。`【待补】放榜后接洽结论`
2. **阈值判据操作化**：韧性状态 Res=1−Sev(H,T)，Sev=Sev_H×Sev_T（深度/历时各设下+上双阈值，Su 2024 式7–9 全文级已核）；但 Su 2024 阈值为按用地外生给定、非识别——本项目须另建"以水力状态量界定失效阈值"的判据。`【已定 2026-08-23】分层合成：单元层物理临界（主体）＋系统/功能层统计断点（工具）；功能层纳入作独立第三维；d·v 包络=物理临界主体之一`
3. **形态→水力系统转译规则**：现有子汇水划分是地形导向，须设计形态导向转译规则。

### 4.2 应对（技术路线一句话，展开见 03）

以"空间结构识别 → 洪水情景与过程模拟 → 过程指标提取 → 形态—响应关系 → 响应—韧性关系 → 直接/中介/替代模型比较"为主线，SWMM 为核心模拟工具，空间句法/多指标为形态测度，洪痕/遥感/监测为校准验证；数据不足案例允许降级为定性对照（不制造伪精确阈值）。
