## C 逐章蒸馏

### ch1 2027 申报环境（分卷1）

**核心观点**
- [作者方法论主张] 「评审信任 = 四链咬合（问题链·研究链·证据链·信息链）+ 项目体量与风险控制」——全书总纲。
- [原书定义] 信息四层级：**正式规则（基金委文件）＞ 公开信息（统计/通告）＞ 评审实践 ＞ 作者判断**；写作时信息层级越高越可靠，层级低的主张要克制。
- [作者方法论主张] 2026 改革后正文为**三部分**（立项依据、研究内容、研究基础），栏目减少、解释责任转移给申请人——「信息四层级」与「以2026为基线、2027核对差异项」是处理时效性的纪律。

**关键概念**
- 「信息四层级」——判断一条写作依据的可信度层级。
- 「以 2026 年度公开提纲为基线，2027 年度如有调整以正式文件为准」——本书对时效性风险的标准处理。

**可执行写作规则**
- [作者方法论主张] 申报启动前先区分「现在可做 / 指南后核对 / 系统开放后确认」三阶段，不提前填未定的栏目。

**原书案例**：无原创案例，以评审流程描述为主。

**适用边界/反例**：正文栏目、字数、系统字段均以年度正式文件为准，本书只能提供评审逻辑的稳定层，不能替代 2027 官方口径。

**对项目帮助层级**：中——确立「信息四层级」的分层纪律；具体栏目待 2027 指南。

### ch2 旧本迁移（分卷1）

**核心观点**
- [作者方法论主张] 迁移旧本不是改词，而是**功能审计**：按功能位置拆开旧本，逐块判断在新本中的去向。
- [作者方法论主张] 五种处置动作：**原位保留 / 移位 / 拆分 / 合并 / 放弃**；每块旧内容在新研究链中必须有新的中间交付（参数区间、分类规则、命题、边界条件）。

**关键概念**
- 「功能位置」——申请书中每一段承担的判断任务，而非其在文档中的物理位置。

**可执行写作规则**
- [作者方法论主张] 表 2.6 旧研究内容向新研究链迁移：原「描述现象与变量关系」→ 保留/重构，交付参数与分类；原「建立模型/实验」→ 保留/拆分，交付命题与证据；原「情境比较/应用分析」→ 合并/降级，交付边界与修正；「额外扩展」→ 删除/后移。

**原书案例**：无具体案例，以迁移表为工具。

**适用边界/反例**：迁移时若新本科学问题已变，旧本材料只能按证据功能重新归属，不能因「以前写过」而保留。

**对项目帮助层级**：中——省基（从国基素材复用）的同类经验；迁移逻辑与「省基缩小版预演复用国基素材」一致。

### ch3 选题（分卷1）

**核心观点**
- [作者方法论主张] 七个概念分层：**研究方向、研究主题、研究现象、现实问题、科学问题、研究任务、项目题目**——「方向不等于问题，题目不等于任务」；选题定不下来常因混淆层级。
- [原书定义] 四级不足：**材料不足 → 技术不足 → 解释不足 → 范式边界**（表3.2）；只有「解释不足」与「范式边界」足以支撑选题，「范式边界」是最强入口。
- [作者方法论主张] 选题逻辑链：**异常 → 前提 → 未知**——从反复出现的异常找共享前提，从共享前提提炼科学未知。

**关键概念**
- 「钩子—瓶颈—靶心」：立项依据的问题呈现法（钩子=异常/失效，瓶颈=现有能力边界，靶心=核心未知）。
- 「问题先行 vs 方法先行」（3.5.2）：看方法是否改变认识边界。

**可执行写作规则**
- [作者方法论主张] 项目切口：改变观察角度、关键假设或证明能力，而非更换工具（3.5.1）。
- [作者方法论主张] 原创性＝改变认识，不是改变名词组合；可行性＝切口与能力匹配（3.6）。
- [作者方法论主张] 热点转化为科学问题：先去掉热词，再看未知是否仍然成立（3.2.3）。

**原书案例**：跨学科微型演示——「系统突然失稳」在环境/医学/信息/管理四个版本中重建问题场景（分卷1 ch10 亦复用）。

**适用边界/反例**：四级不足中「技术不足」非低价值，但申请人必须说明技术改进改变了什么**认识能力**，不能只承诺性能指标提高（3.4.3）。

**对项目帮助层级**：**高**——「解释不足/范式边界」定位可用于区分国基候选 G1/G2/G3 的缺口层级（**候选假说，需文献路线审计确认，见项目映射快照 §2.4**）；「范式边界」与文献硬伤清单互补。

### ch4 摘要（分卷1）

**核心观点**
- [作者方法论主张] 四句话＝四个判断单元：①**科学矛盾**（最少背景建立核心未知）→②**项目切口**（从哪里进入、为何是这里）→③**研究路径**（让评审看见一条研究链）→④**认识增量**（学科会多知道什么）（4.2.1–4.2.4）。
- [作者方法论主张] 三版本摘要：工作摘要（选题阶段检验四判断闭合）→ 正式摘要（从稳定正文反向抽取）→ 最终摘要（先校验承诺再处理字数语言）（4.3）。
- [作者方法论主张] 六类高风险摘要（4.8）：宏大叙事型、多问题并列型（问题没站住）；方法堆砌型、任务清单型（路径没形成）；论文式、过度承诺型（承诺与证据不匹配）。

**关键概念**
- 「双向一致性」：摘要与题目、正文互查，每个高强度动词（揭示/建立/突破）必须在正文有落点。

**可执行写作规则**
- [作者方法论主张] 压缩三轮删除（4.4）：优先保留「改变项目判断」的信息；优先删除不改变首轮判断的材料；**谨慎删除**限定条件、科学动作和前后关系。
- [作者方法论主张] 四轮审校顺序（4.9）：结构 → 密度 → 一致性 → 语言（**先改项目逻辑，最后才改句子**）。

**原书案例**：无完整案例，五条贯穿路线演示同一项目压缩成四判断单元（4.7）。

**适用边界/反例**：四判断单元是**判断骨架**，不是固定句式；不同学科四句话的「证据语法」不同（4.5 五类研究形态判断重心不同）。

**对项目帮助层级**：**高**——以四判断单元为骨架重构省基/国基摘要（具体重构见项目映射快照 §2.1）；「认识增量」句须写出给定耐受阈值下的响应与韧性差异。

### ch5 立项依据（分卷1）

**核心观点**
- [作者方法论主张] 六个功能节点（表5.1）：**问题场景 → 现有能力 → 能力边界 → 根本矛盾 → 项目切入 → 科学价值**；由问题场景逐步收敛到科学价值的论证漏斗。
- [作者方法论主张] 钩子—瓶颈—靶心：钩子写异常/失效，瓶颈写共享能力边界，靶心写核心未知；靶心需先确认真实存在，再决定写法（3.1 末）。
- [作者方法论主张] 根本不足四级（5.4.1）：**材料不足 / 技术不足 / 解释不足 / 范式边界**；建立「失效—前提—未知」推理链（5.4.3）。

**关键概念**
- [原书定义] 科学问题四要素（5.5.2）：**研究对象 / 条件与约束 / 核心未知 / 可观察后果**。
- 「文献路线四问」（5.3，表5.3）：一类研究路线的评述四环节——**能力与贡献 → 适用前提 → 能力边界 → 项目关联**。

**可执行写作规则**
- [作者方法论主张] 先排除四种相近表述再写科学问题（5.5.1）；切入点＝改变默认视角，而非更换工具（5.5.3）。
- [作者方法论主张] 边界声明：主动说明本项目不解决什么（5.5.4）。
- [作者方法论主张] 科学价值回到前文核心未知：回答之后改变什么认识（5.8.1）；价值、创新与预期成果三者区别（5.8.3）。
- [作者方法论主张] 参考文献四功能：让引用成为论证证据，不是文献陈列（5.9）。

**原书案例**：5.6 贯穿案例「同一项目从宽背景收敛到项目切入」。

**适用边界/反例**：四问缺第一问＝成果陈列；只写第三问＝为立项而挑错；四问共同出现才公允（5.3）。

**对项目帮助层级**：**高**——「科学问题四要素」用于省基 3 个工作版科学问题与国基候选 G 问题的检验（对象=空间形态参数、条件=洪水情景与村落类型、未知=响应/关联特征、可观察后果=水力状态量与韧性指标）；四问评述用于立项依据的路线综述。

### ch6 研究内容（分卷1）

**核心观点**
- [作者方法论主张] 科学问题→子科学问题→**研究单元**→研究链；研究链三条件：不可跳过的问题顺序、明确的单元接口、可检验的阶段结果。
- [作者方法论主张] 真闭环四组成（6.7.1）：**问题链（为何按此顺序）/ 信息流（交付什么）/ 证据流（同一判断多层证据）/ 反馈关系（后续修正前面判断）**——闭环的标志是结果「回用」，不是箭头多少。
- [作者方法论主张] 六类伪闭环（6.7.2）：主题相同型、方法重复型、箭头装饰型、数据共用型、结论拼接型、**应用跳转型**（研究链末端突然跳向对策/应用，未使用前文阈值/命题/边界）。

**关键概念**
- 五类研究链原型（6.4）：①结构识别—机制揭示—边界验证；②理论命题—模型推导—经验或数值检验；③问题形式化—方法构建—性质证明—性能验证；④现象发现—因果识别—机制或干预检验；⑤机理假设—多层实验—理论修正或系统解释。
- 单单元六判断（6.6，表6.6）：主导子问题 / 逻辑位置 / 方法必要性 / 阶段结果 / 下游接口 / 风险与替代。

**可执行写作规则**
- [作者方法论主张] 三块式/四块式由研究链自然推导，先定研究链再定块数（非先定形式再填任务）。
- [作者方法论主张] 四快速检验（6.7.3）：**顺序交换测试 / 删除单元测试 / 输入输出测试 / 反向校验测试**。
- [作者方法论主张] 创新「分布式证据＋集中式提炼」（6.8）：创新点须能回指研究单元与验证方式；四类伪创新＝名词升级、工具换新、场景替换、「首次」声明。
- [作者方法论主张] 年度计划按「证据—里程碑—风险」组织（6.9）；Plan-B 保留核心问题、收缩实现路径，**不是另一套完整项目**（6.9.4）。

**原书案例**：6.6.7 极端天气配送网络重组（并列任务重组为一个研究单元）；6.7.4 共享出行供需波动（箭头很多→结果真正回用）。

**适用边界/反例**：方法重复型伪闭环常见于「同一方法分析不同样本再各列一块」；数据共用型（多块共用同一数据）不算闭环。

### ch7 研究基础（分卷1）

**核心观点**
- [作者方法论主张] 研究基础不是简历缩短版，而是**证据链**：问题积累 → 方法准备 → 初步证据 → 条件保障 → 风险控制 → 项目可执行性。
- [作者方法论主张] 三个锚点＋角色锚：问题锚 / 方法锚 / 资源锚 / **角色锚**（成果相关不等于个人贡献清楚）；锚点不必一一对应成果。
- [作者方法论主张] 五维证据矩阵（7.6）：科学问题—研究内容—关键方法—前期证据—责任成员逐项对应；用「**最弱环节**」判断研究基础是否成立。

**关键概念**
- 证据强弱四层（7.1.2）：了解概念 → 相邻问题用过 → 相近对象初步验证 → 直接可用的参数/样本/命题；核心风险环节至少需第三层。
- 三种合格初步结果（7.3.2）：可运行 / 可解释 / 可扩展。

**可执行写作规则**
- [作者方法论主张] 用「已解决—已暴露—待推进」组织前期工作（7.2.2）；「已暴露」是研究基础与立项依据的接口。
- [作者方法论主张] 区分执行风险（可预防替代）与科学风险（可解释可收敛）（7.8.1）。
- [作者方法论主张] 成果少但关键路径跑通，强于成果多但核心环节空缺（7.5.2）。

**原书案例**：7.4 各研究形态「最难承诺—真正证据—证明力有限材料—尚缺条件」矩阵（A–E 线）。

**适用边界/反例**：把其他学科的「强证据」直接搬来＝偏差（用论文数量代替实验重复性）；平台等级不等于样本可获得性。

**对项目帮助层级**：**高**——你正处「省基准备申报」阶段；方法锚（SWMM/空间句法/GRA/SPC 是否真实跑过）与资源锚（案例村落数据可及性）是可行性的核心；「最弱环节」预演直接对应已核验的「验证/率定数据」弱链；最难承诺=可率定的洪涝响应模型（见项目映射快照 §2.6）。

## D 案例卡片

本书案例形态特殊：**全部为作者原创示例**（非真实申报书），且均为文/管/医/信/心/教类，无建筑/城乡规划类。按「内容为参照系，学逻辑不学词汇」处理。以下 3 个为代表深度卡。

### 深度卡 1：极端天气配送网络重组（分卷1 ch6.6.7）

- **案例名+出处**：「某项目研究极端天气下的配送数据……建立优化模型」——分卷1·6.6.7。
- **原书如何凝练**：原拟「采集数据+比较策略+建立模型+分析规模差异+仿真验证」五项并列任务 → 重组为单一主导子问题「局部节点失效与需求积压共同作用时，配送网络恢复顺序如何结构性变化」，其余任务降级为参数设定/结论检验。
- **写作层次结构**：主导子问题 → 上游依赖（前一单元交付）→ 方法必要性（静态模型无法识别时序耦合）→ 阶段结果（结构性质/关键阈值/失效条件）→ 下游接口 → Plan-B 边界。
- **可迁移的规范与数字**：单研究单元六判断表；「修改的重点不是把五项任务写得更漂亮，而是让它们围绕一个主导子问题重新获得位置」。
- **对项目的可迁移逻辑**：省基 RC1–RC3 若各块只并列任务，需重构为单一主导子问题驱动的链——以「形态—防御单元特征与洪涝响应、韧性表现的对应关系」为主线，使 RC1 形态转译交付参数进入 RC2 模拟、RC2 输出的水力状态量进入 RC3 评估与比较、比较结果反向检验 RC1 的类型划分。
- **边界与局限**：配送网络是工程优化问题，证据形态（动态模型/阈值命题）与建筑学的空间—淹没耦合不同，学的是「任务→子问题→接口」的重组逻辑，不是模型本身。

### 深度卡 2：共享出行供需波动——从箭头很多到结果回用（分卷1 ch6.7.4）

- **案例名+出处**：共享出行供需波动反例与修正——分卷1·6.7.4。
- **原书如何凝练**：原设计「需求分析→定价模型→司机响应→调度策略」四模块首尾相连但互不调用 → 修正为信息流：需求参数进入定价模型、价格阈值进入司机行为检验、行为响应函数进入调度、调度结果反向修正定价机制在极端波动下的失效边界。
- **写作层次结构**：问题链（不可跳过顺序）→ 信息流（参数/阈值/函数依次传递）→ 证据流（行为检验约束机制命题）→ 反馈（反向修正失效边界）。
- **可迁移的规范与数字**：真闭环四组成；四快速检验（顺序交换/删除单元/输入输出/反向校验）；「闭环来自结果回用，而非模块排列」。
- **对项目的可迁移逻辑**：对照 RC1–RC3：RC1 类型判据与形态参数是否真的进入 RC2 的 SWMM 情景设定？RC2 淹没结果是否以指标形式进入 RC3 韧性评估？三村比较结果是否反向检验 RC1 的类型划分假设？任一环节若各自独立，即伪闭环。
- **边界与局限**：共享出行的「行为响应」依赖心理学/经济学证据，「形态—韧性」依赖空间分析与水动力模拟证据；借鉴的是接口设计与反向校验的结构，不是行为实验方法。

### 深度卡 3：智能建议与管理者责任预期（管理行为线 E，分卷1 ch7.4.3 + ch10）

- **案例名+出处**：管理行为研究形态——「智能建议与管理者经验冲突时责任预期如何改变信息采纳」——分卷1·7.4.3（研究基础侧）。
- **原书如何凝练**：最难承诺＝区分「不同意建议/不信任系统/担心责任」三种相近解释，证明责任预期改变信息权重而非简单降低采纳率；前期证据＝任务预试、构念区分、过程记录、识别预演，而非论文数量。
- **写作层次结构**：最难承诺 → 真正证据 → 证明力有限材料 → 尚缺条件及落实 → 放置边界（研究基础/研究内容/简历各归其位）。
- **可迁移的规范与数字**：研究基础四步证据链；「相关但证明力有限」判定；证据强弱四层。
- **对项目的可迁移逻辑**：关键证据形态＝案例村落的形态量化（空间句法）+ 淹没模拟（SWMM）的前期跑通 + 数据可及性——最难承诺对应「洪涝响应模拟在真实村落能否率定」，前期证据须直接回答这一条，而不是罗列论文。
- **边界与局限**：管理研究依赖构念/任务/识别条件；建筑学依赖空间分析工具与水动力模型可及性。借鉴的是「用最弱环节定证据优先级」，不是管理学变量体系。

## I 一页纸总蒸馏（本书对项目最有价值的 10 条）

1. **评审信任＝四链咬合+体量控制**——申请书一切判断围绕让评审在有限时间形成稳定信任。（分卷1·ch1）
2. **科学问题四要素**：对象/条件与约束/核心未知/可观察后果——检验省基 3 个工作版科学问题与国基候选 G1/G2/G3。（分卷1·5.5.2）
3. **四级不足**：材料/技术/解释/范式边界——缺口定位到解释不足与范式边界才是强入口；省基按「相对不足」区域版表述。（分卷1·3.4.3）
4. **摘要四判断单元**：科学矛盾—项目切口—研究路径—认识增量；四轮审校先改逻辑后改句子。（分卷1·ch4）
5. **立项依据钩子—瓶颈—靶心 + 四问评述**（能力/前提/边界/关联），科学价值回到核心未知。（分卷1·ch5）
6. **研究链＝问题链+信息流+证据流+反馈**；四快速检验（交换/删除/输入输出/反向校验）。（分卷1·ch6）
7. **六类伪闭环**——尤其「应用跳转型」（直击 RC3 后保护诊断）与「方法重复型」（直击三村比较）。（分卷1·6.7.2）
8. **研究基础＝最难承诺的证据覆盖**（分卷1·ch7）——成果多少不是核心，关键路径是否真实预演、可率定才是；当前最难承诺=山区+圩区两模型可率定（西河/大通外洪边界）。
9. **单单元六判断**审计每个研究单元（RC1–RC3）；Plan-B 保留核心问题、收缩路径、说明代价。（分卷1·6.6/6.9.4）
