# 13 三案例可比性审计表（执行门第一关）

> 用途：案例准入门（先于结果）。回答四问——①皖江可区分哪些水环境—营建情境；②查济/西河/大通分别为什么能代表该空间组织模式；③标准是否先于结果；④有无更符合却被排除的案例。**主学科口径：案例=三种「聚落空间应对水环境的营建模式」，不是三个水文情景**（水文情景只是各自的验证情境，属 RC2 证据层）。
> 关联：[[10 项目内核]] §3（类型/三村设计）、§4.8 执行门；[[11 数据准入闸门表]]（数据可行性交叉）。
> 状态纪律：形态特征与典型性论证属**可推定的建筑学判断**；「数据可得/更优案例」须实地/文献核验，标【待核验】，不得写成事实。

## 核心软肋（先自问，不回避）

三村的空间组织模式与其水环境约束**成因上绑定**（约束是模式的成因），故「空间组织模式差异」与「水文约束差异」在三村上**必然共线**。主学科检验要的不是否认共线（内核 §3 已声明不分离类型/梯度效应），而是确认：**撕掉水文情景标签后，三村在空间组织形态上仍是三种可区分的类型**——查济「溪谷—街巷—水系耦合」、西河「圩堤—内部排水—聚落围护」、大通「岸线—口岸—街巷—防御边界临江」——而非仅在水文情景上不同。本表 §2 逐村验证这一点。

## 1 皖江可区分的水环境—营建情境（候选清单）

| 水环境约束 | 空间营建响应逻辑 | 形态关键词 | 皖江落点 |
|---|---|---|---|
| 山地支流（坡面汇流快、洪水历时短、水位暴涨暴落） | 依水就势、顺溪展开、水系作骨架 | 溪谷—街巷—水系耦合 | 皖南山区（泾县查济一带） |
| 圩区（外河水位高、内水难排、顶托） | 围护收束、堤内自成排水单元 | 圩堤—内部排水—聚落结构 | 青弋江/水阳江圩区（芜湖西河一带） |
| 沿江洲地/口岸（四面环水、顶托+内涝） | 沿江展开、口岸驱动、防御边界临江 | 岸线—口岸—街巷—防御边界 | 长江洲地（铜陵大通—和悦洲） |

> 说明：三情境是皖江可区分的**水环境约束梯度**，不是本项目发明的类型；类型是**约束下形成的空间营建模式**（见 §2）。

## 2 三案例逐一对表（建筑学类型验证）

### 查济 —— 溪谷—街巷—水系耦合的空间组织

| 项 | 内容 |
|---|---|
| 水环境约束（验证情境） | 山地支流，坡面汇流、山洪历时短 |
| 空间组织模式 | 水系作聚落骨架，建筑顺溪错落，街巷—水渠—建筑耦合组织 |
| 关键形态特征（可测） | 溪流走向与街巷关系、建筑沿溪高程关系、水口/塘池位置、排水路径 |
| 为什么能代表该模式 | 溪谷水环境约束下聚落「依水就势」组织的典型；水系与街巷、建筑的耦合关系是皖南山区聚落的代表性组织方式 |
| 典型性风险 | 查济规模大、旅游开发重，形态是否被改造？「耦合型」是否混入圩区/沿江要素？【待核验】 |
| 数据可行性 | 11 表 M1–M5 多【确定可得/待协调】，W 门以山洪情景为主，风险低于圩区 |

### 西河 —— 圩堤—内部排水—聚落结构的围护型组织

| 项 | 内容 |
|---|---|
| 水环境约束（验证情境） | 圩区，外河高水顶托、内水难排 |
| 空间组织模式 | 聚落被圩堤围合，堤内自成排水单元，聚落结构与排水组织嵌套 |
| 关键形态特征（可测） | 圩堤走向/高程、聚落—堤关系、内部排水网络、塘池蓄滞位置 |
| 为什么能代表该模式 | 圩区水环境约束下聚落「围护收束」组织的代表；堤—排水—聚落三者关系是圩区聚落的组织核心 |
| 典型性风险 | 圩堤/断面/排水调度数据**高风险缺失**（11 表 W4/W5/W6）；若数据不足只能降级为对照，则「围护型」是否还有第二个代表村？【待核验】 |
| 数据可行性 | 11 表 W6=核心卡点，击穿 NC；首轮部门接洽前「典型性」论证不实 |

### 大通 —— 岸线—口岸—街巷—防御边界的临江型组织

| 项 | 内容 |
|---|---|
| 水环境约束（验证情境） | 沿江洲地/口岸，外洪顶托+内涝 |
| 空间组织模式 | 聚落沿江岸线展开，口岸驱动街巷格局，防御边界临江布置 |
| 关键形态特征（可测） | 岸线—街巷关系、口岸位置、防御边界（堤/墙）、街巷层级 |
| 为什么能代表该模式 | 沿江洲地/口岸聚落「临江展开」组织的代表；岸线—口岸—街巷—防御边界四者的组织关系是洲地聚落的组织核心 |
| 典型性风险 | 和悦洲图档/圩堤单独体系待核（11 表 M1/M6）；「临江型」与「围护型」边界是否清晰（大通也有堤）？类型纯度待辨【待核验】 |
| 数据可行性 | 11 表 M1 图档【待协调】、W6 和悦洲【高风险缺失】，击穿 C1+NC |

## 3 标准是否先于结果

| 判据 | 现状 |
|---|---|
| 分类判据 | 水环境约束 + 空间营建体系 + 防御构造组织（内核 §3）——三者均**可在任何模拟前独立判读** |
| 是否依赖模拟结果 | 否（禁止按模拟结果事后分「高/低韧性型」） |
| 判据可操作性 | 水环境约束可查水文地貌；空间营建体系需 RC1 形态刻画支撑（现有文献是否已把三村归为该类型，还是本项目首次提——【待核验】） |
| 结论 | 判据先于结果**成立**；但「三村=三种模式」的**典型性**仍依赖 §2 待核验项 |

## 4 排除案例审计（有无更符合却被排除）

| 模式 | 皖江候选 | 是否被排除 | 排除理由 | 诚实性检查 |
|---|---|---|---|---|
| 溪谷耦合型 | 查济 / 宏村 / 屏山等皖南聚落 | 选查济 | 研究基础（既有测绘/资料）+ 山洪情景清晰 | 宏村水系统更著名，是否因「研究基础方便」而非「典型性」排除？【待核验】 |
| 圩堤围护型 | 西河 / 芜湖、宣城其他圩区村落 | 选西河 | 传统水运古镇、图档相对多 | 是否因西河图档多而牺牲「圩区典型性」？【待核验】 |
| 岸线临江型 | 大通—和悦洲 / 其他江心洲 | 选大通 | 口岸洲地形态独特 | 大通口岸功能强，是否「口岸性」压过「洲地性」，混入两重逻辑？【待核验】 |

> 诚实性检查是本表核心：**若三村是被「数据/资料可得性」而非「类型典型性」选中的，则「三种空间应对模式」的论证不实**，题目中「三类典型」须降为「三个案例」（最安全表述见内核 §3）。
