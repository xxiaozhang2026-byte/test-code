# 11 数据准入闸门表（双证据门：查济 / 西河 / 大通）

> 用途：P0 数据门。从「水力数据表」升级为**双证据门**——RC1 形态证据门 + RC2 水力证据门，回答「内核承诺需要什么证据、现实能不能给」。逐项标 **已得 / 确定可得 / 待协调 / 高风险缺失**。**状态为 2026-08-29 基于 [[22 案例数据可及性核验清单_20260821]] 线上预查与交接 §4.2 风险排序的推定，未经实地/部门核验，不得写成已核实事实**。每项标「击穿」=缺失会击穿内核 V0.2 的哪条承诺。
> 关联：[[10 项目内核]]、[[22 案例数据可及性核验清单_20260821]]、CHATGPT_RESEARCH_HANDOFF §4/§9-P0。
> 用法：实地调研 / 部门接洽逐项更新，打勾即把推定升级为事实；记来源与负责人。

## 证据性质纪律（RC1 门专用）

> **可直接测量的形态事实**（平面/轮廓/高程/网络，可作水力转译的事实输入）与 **历史/口述功能解释**（「这个塘过去用于泄洪」等营建口述）严格分开。**功能解释只是解释线索，不等于水力事实**；只有经转译规则落成可测参数后才进入模型。RC1 不是「SWMM 前处理」，而是有建筑学知识生产功能的研究单元。

## 高风险缺失清单（按击穿强度排序）

1. **圩堤矢量与堤顶高程（W6，西河/大通）**——击穿 NC。交接风险 #1；线上不可替代，须首批部门接洽；和悦洲为江心洲圩堤、与江堤不同体系，单独核验。
2. **圩区回水/漫溢/外洪顶托表达能力（W4/W5，西河/大通）**——击穿 NC + R2。SWMM 适用性预实验核心命题（交接 §3.2）：试建后若不能表达→补 HEC-RAS 或二维。
3. **圩区 DEM 精度（W1，西河/大通）**——击穿 NC + R2。判据=试算能否分辨圩堤走向与内部微地形。
4. **率定/验证资料（W10，三村）**——击穿 R3。村落级实测淹没少，策略=模拟为主、历史单场次校准；率定质量被异质水文边界摊薄（风险 #3）。
5. **大通 M1 图档（和悦洲）**——击穿 C1。若洲体平面/岸线资料不足，RC1 转译规则三村共用性在大通收缩（触内核 §4.6 数据准入：数据不足→降级对照）。
