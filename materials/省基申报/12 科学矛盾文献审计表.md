# 12 科学矛盾文献审计表（认识门第一关）

> 用途：检验科学矛盾（L1）是否成立。**成立判据**（依《基金的逻辑》ch3「异常→前提→未知」）：多条已有研究**共享同一默认前提**，且**恰因该前提而解释不了某个稳定异常**。本表不预设结论，逐条审计三个候选共享前提，回答两问：**前提是否真的被共享？是否已出现该前提解释不了的稳定异常？**
> 关联：[[10 项目内核]] §2（科学问题三句判断＝前提＋异常）、§4.4（本表）、§4.8 认识门；[[11 数据准入闸门表]]。
> 状态纪律：**本表是审计工具，不是结论**。「证据录入」列留空待检索，检索前不得填「已确认」。检索动作与来源进「核验记录」。

## 判定口径（先定标准，再填证据）

| 结果 | 判据 |
|---|---|
| **前提「共享」** | 找到 ≥2 条相互独立的研究，把该默认前提当作免证起点（非个别作者观点） |
| **异常「存在」** | 找到稳定反复出现、且用该前提无法自洽解释的经验/文献证据 |
| **科学矛盾成立** | 前提共享 + 异常存在（可作为立项依据「钩子—瓶颈—靶心」） |
| **降级 gap 型** | 只有前提共享、无稳定异常 → 退回「缺乏统一转译/检验框架」表述 |
| **删除该条** | 前提本身不成立（文献并不共享）→ 不得硬立矛盾 |

## 三个候选共享前提审计

### 前提①：静态形态/营建特征被当作稳定防御能力代理

| 审计项 | 内容 |
|---|---|
| 前提原文 | 既有研究把静态空间形态/营建特征（台基高差、街巷排水格局、塘池蓄滞、水口）直接当作稳定防御能力代理 |
| 审计子问题 | a. 传统村落防灾/水适应性文献是否普遍用静态形态特征直接推断防御能力？b. 是否默认该能力不随时间/水文条件变化（缺动态/条件依赖讨论）？c. 是否存在反例：同一形态特征在不同水文条件下衰减/失效/反向？ |
| 证据检索方向 | 中文：传统村落防洪 / 聚落水适应性 / 水智慧 / 历史聚落防灾；英文：flood adaptation in historic settlements / traditional water management / vernacular flood resilience |
| 判定 | 先证「静态形态→防御能力」是默认定式（非个例），再找「条件依赖失效」反例 |
| 证据录入 | （待检索） |
| 状态 | 【待检索】 |

### 前提②：防御功能默认单调正向，少讨论衰减/反转/重分配

| 审计项 | 内容 |
|---|---|
| 前提原文 | 防御功能被默认单调正向（堤越高越安全、塘越多越能蓄），少讨论随水文边界的衰减/反转/重分配 |
| 审计子问题 | a. 既有研究是否默认防御设施「越多/越强越好」？b. 是否讨论过度防御的负效应（圩堤封闭→内涝、蓄滞→淹没时空重分配/转移）？c. 有无防御措施在特定条件下加重或转移淹没的证据？ |
| 证据检索方向 | 中文：圩区内涝 / 蓄滞洪区淹没 / 圩堤防洪；英文：levee effect / levee paradox / flood risk transfer / compound flooding |
| 判定 | 前提成立需「防御单调正向」为默认；异常需「防御加重/转移淹没」证据 |

### 前提③：韧性/防洪评价假定一套指标可跨洪涝机制直接比较

| 审计项 | 内容 |
|---|---|
| 前提原文 | 韧性/防洪评价假定一套指标（淹没深度/历时/损失）可跨洪涝机制（山洪/内涝/外洪顶托）直接比较 |
| 审计子问题 | a. 既有评价是否用同一套指标跨不同洪水来源直接比较？b. 不同洪涝机制下同一指标的可比性是否被质疑（时间尺度、暴露方式、致灾机制不同）？ |
| 证据检索方向 | 中文：洪水韧性评价 / 灾害韧性测度 / 洪涝风险；英文：flood resilience assessment / multi-hazard comparability / compound flood metrics |
| 判定 | 前提成立需「一套指标跨机制比较」为默认；异常需「不同机制下指标不可比/需分机制」证据 |
