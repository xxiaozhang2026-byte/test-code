# 文献库维度矩阵

> 全库结构化扫描：每篇统一标注 **方法 / 空间尺度 / 是否测阈值 / 是否检验中介路径 / 研究对象 / 境内外**。
> **用途**：G1/G2/G3 缺口逐格证明（阈值列、中介列全否 = 缺口成立）；创新配置的反例定位；综述缺口段写作底稿。
> 深度标注：🟢已精读（四问）· 🟡四问待精读 · 🔵扫描待（工具/背景类，摘要要点级）。

## 读法（关键判别列）

- **阈值** = 是否识别**系统级韧性/失效阈值**（非"权重/建设强度区间"）。全"否"→ G3 成立。
- **中介** = 是否检验"**形态→洪水响应过程→韧性**"完整因果路径。全"否"→ G2 成立。
- **尺度×方法**：村落尺度量化止于单村 SWMM 性能评估、无跨案例系统比较、无"形态→水力系统转译"→ G1 成立并具体化。

## 结构发现（供创新点/科学问题凝练）

1. **G3 阈值缺测：全库 0 篇测系统级阈值**（"否"贯穿全表）。C 组量化评估均止于"指数/分级"，无失效阈值识别。
2. **G2 中介缺环：全库 0 篇检验"形态→洪水响应→韧性"完整因果路径**（"否"贯穿全表）。
3. **G1 尺度缺位具体化**：村落尺度量化 = 单村 SWMM 性能评估（[[yujia2025]]/[[benzhai2026]]/[[lianghuaqiu2022]]），无跨案例系统比较、无"形态→水力系统转译"；形态量化多在城市/街区尺度（C 组）。**关键证据：[[zhaohongyu2018]]→[[yujia2025]] 为同一团队（赵宏宇）同一村落（于家古村）的"定性→SWMM 定量"演进（量化至 49 子汇水区/106 管道/19 调蓄池、调蓄容积 4966.27m³、2/5/10/50 年重现期）——即便同村完成定量，仍止于单村性能评估，无跨案例比较、无阈值识别。** 佐证：[[panying2021]] 引赵宏宇、车越《传统村落生态治水智慧》为理论来源，表明"生态治水智慧→村落量化"已成为多团队共享纲领，但该文层面仍止于流域定性类型学。
4. **B 组缺口验证**：[[qiumingli2021]] 乡村韧性综述、[[wilson2018]] 社区韧性实证、[[cunzhuang-renxing-zhangleqin]] 村庄韧性综述，均无村落形态—洪水响应机制。
5. **G2 精确化（2026-08-21 C 组精读修正）**："形态→洪水响应"在**城市/街区尺度已被物理建模**——[[urban-form-flooding]]（Balaian et al., 2024, Nature Communications）以统计力学平均流理论给出无量纲洪水深度 ∝(1−φ)(1+bχ)/√α、有效弦长普适标度，证明"形态→洪水"物理路径存在。故 **G2 缺口须精确表述**为：(a) 该物理理论**未延伸至"洪水→韧性"**（阈值/系统转制，仍归 G3）；(b) **未下沉到传统村落尺度**（合成方形建筑、1km 累计尺度不适用坡地/院落/巷弄/塘池村落形态）；(c) 国内形态韧性量化（[[luoyang-lishijiequ-xingtai]]→[[taiyuanjie-yuhong-renxing]]→[[doumen-lishijiequ-xingtai]] 三案例谱系）均为**静态指标+AHP 权重+分级**，指标为拓扑/几何量、**无水力过程**——"村落形态→水力系统转译→洪水响应"完整中介路径仍无人检验。
6. **G1 精确化（2026-08-21 补充）**：形态—韧性量化在城市/街区尺度已成成熟谱系（洛阳 94ha/1300 产权地块/7524 建筑基底→太原街 10 指标→斗门 I-V 分级），且 **[[luoyang-lishijiequ-xingtai]] 基金为"西南地区传统村落保护与利用研究"（18ZDA161）**——村落保护重大课题资助的却是历史街区形态韧性方法，恰证"村落尺度形态韧性量化"缺口是公认空白、已有需求信号。
