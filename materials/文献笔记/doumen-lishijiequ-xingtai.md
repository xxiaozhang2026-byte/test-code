# 历史街区形态韧性评估体系构建及量化研究——以珠海市斗门旧街为例

## 摘要

以珠海市斗门旧街为研究对象，基于城市形态学理论构建历史街区形态韧性评估指标体系，采用专家打分与 AHP 层次分析法确定指标权重，通过从优隶属度标准化与加权求和得到韧性指数并进行等级划分，实现对历史街区形态韧性的量化评估。结果表明斗门旧街总体处于 III 级中等韧性水平，其街巷系统连通性、地块模块性、建筑肌理稳健性、土地利用多样性四个准则对形态韧性的影响各异，可为历史街区的保护与更新提供量化依据。

关键词：历史街区；形态韧性；评估体系；AHP；斗门旧街

## 研究问题（真实问题）

- **表面问题**：构建历史街区形态韧性评估体系并量化评估斗门旧街。
- **真实问题**：把 [[luoyang-lishijiequ-xingtai]] 的"形态区域+形态韧性"量化方法移植到新的历史街区案例（珠海斗门旧街），以专家打分 + AHP + 从优隶属度标准化 + 韧性指数分级实现可复制的形态韧性量化评估——方法谱系的复制与应用扩展。
- 核心命题：以街巷系统连通性、地块模块性、建筑肌理稳健性、土地利用多样性四准则可量化历史街区形态韧性并分级（I-V 级）。

## 核心观点

- **准则层与权重**：街巷系统连通性 0.2578、地块模块性 0.1653、建筑肌理稳健性 0.3169、土地利用多样性 0.2611——**建筑肌理稳健性权重最高（0.3169）**，与 [[luoyang-lishijiequ-xingtai]] 的稳健性 0.3046 居首一致。
- **方法与流程**：专家打分 + AHP 权重 + 从优隶属度标准化 + 加权求和 → 韧性指数 → **5 级等级划分（I-V）**。
- **斗门旧街实证**：总体 III 级中等韧性水平；**分维值偏大、形状指数高**（长条形、破碎化形态特征）；古建筑韧性高。
- 结论性质：形态韧性等级为保护与更新提供量化依据。

## 方法与材料

- 方法：专家打分 + AHP 层次分析法 + 从优隶属度标准化 + 加权求和 + 韧性指数 5 级分级。
- 数据：珠海斗门旧街形态数据（街巷/地块/建筑/用地）。
- 数据性质：**静态空间形态指标 + 专家权重**；无水力模型、无洪水过程、无系统阈值。

## 结论与启发（精读后压缩）

**机制判断**：斗门旧街形态韧性以四准则（街巷连通/地块模块/建筑稳健/用地多样）专家打分 + AHP + 从优隶属度标准化 + 韧性指数 I-V 级分级评估，建筑肌理稳健性权重最高，总体 III 级中等韧性——是[[luoyang-lishijiequ-xingtai]] 方法的案例复制，属**静态指数+分级**评价，非"形态→洪水响应→韧性"过程检验。

**可用于申报书的支撑句**：历史街区形态韧性评估以专家打分 + AHP 加权 + 从优隶属度标准化 + 韧性指数 5 级分级为流程（准则权重：建筑肌理稳健性 0.3169、街巷连通性 0.2578），珠海斗门旧街总体 III 级中等韧性（许秀娟, 2024）——为本研究提供：①**G1 精确化证据**：历史街区形态韧性量化已在街区尺度形成可复制流程（洛阳→太原街→斗门三案例方法谱系），**传统村落尺度仍缺位**；②**G2 确认**：其四准则为**静态形态属性**，街巷连通性为**拓扑可达**（同 [[sunying2015]] 语义红线），**无任何水力过程**；③**G3 确认**：**I-V 级韧性分级是加权指数分级，非系统转制阈值**；④**可借鉴**：其"从优隶属度标准化+韧性指数分级"可作本研究村落形态韧性分级的**方法参考**，但本研究须以水力模拟产生洪水响应、以阈值识别替代专家权重分级。

## 精读分析（四问）

### 前提假设（三档）

- **明说**：①城市形态学四准则可表征历史街区形态韧性；②专家打分 + AHP 权重合理；③从优隶属度标准化与 5 级分级恰当；④斗门旧街为代表案例。
- **未明说**：①**形态→韧性的映射是静态指数**——四准则未经验证其对实际扰动的响应；②专家权重为主观判断；③"III 级中等韧性"为加权指数值，**无失效/转制临界语义**；④分维值/形状指数与韧性的关系为形态学推断，无过程验证；⑤单一案例、无跨案例比较。
- **高风险**：①"I-V 级韧性分级"若被当作**阈值**引用属方法误用（分级≠系统转制阈值）；②"中等韧性"若被当作**防洪性能**引用属对象错配（面向形态保护，非洪水）；③"街巷连通性"若被当作**水力连通**引用属语义错误（拓扑量）。

### 创新点

- 类型：**方法应用/案例复制层创新**（AHP+从优隶属度标准化应用于新案例）。
- 新引入：①从优隶属度标准化步骤（较 [[luoyang-lishijiequ-xingtai]] 更细的标准化处理）；②韧性指数 I-V 级划分。
- 与最近文献差异：对 [[luoyang-lishijiequ-xingtai]]（方法开创）＝案例复制+流程细化；对 [[taiyuanjie-yuhong-renxing]]（雨洪语义）＝回到形态保护语义。
- **新意判断：弱偏中**。方法增量有限（标准化步骤/分级细节），主要是案例扩展；无水力过程、无阈值。

### 证据评估

- 直接支持：斗门旧街产出韧性指数与等级分布 → **评估流程可操作、可复现**。
- 仅间接支持："古建筑韧性高""III 级中等韧性"为指标权重+空间格局推断，无实际扰动响应记录。
- 缺失 baseline：①无水力模型/洪水过程；②无实测/灾损验证；③无跨案例比较；④无时间序列；⑤村落尺度缺位。
- **证据-结论匹配度：中偏低**。作为方法复制演示成立；"韧性等级"为静态指标合成，未经验证。申报书定位：作 **G1 街区尺度证据与方法谱系一环**，不作防洪机制证据。
